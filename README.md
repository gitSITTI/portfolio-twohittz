# portfolio-twohittz

Public portfolio and ecosystem overview for Edgar Sosa, deployed to Cloudflare Pages at `portfolio.twohittz.com`.

## Stack

- React + Vite + TypeScript
- Tailwind CSS
- Cloudflare Pages via Wrangler

## Development

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

First deploy publishes to `https://portfolio-twohittz.pages.dev`. After that, add the custom domain `portfolio.twohittz.com` in the Cloudflare Pages dashboard.

## Content

All visible page copy lives in `src/data/content.ts`.
